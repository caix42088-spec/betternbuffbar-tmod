# 持续使用防误触 UI / Uninterrupted Use

独立的客户端模组，版本 **1.0.1**。针对 Terraria **1.4.4.9**、tModLoader 稳定版 **v2026.07.3.0** 制作并编译验证（2026-09-30）。稳定版依据：[官方发布页](https://github.com/tModLoader/tModLoader/releases/latest)。

## 安装

1. 在 tModLoader 中打开“创意工坊 → 管理模组 → 打开模组文件夹”。
2. 把 `UninterruptedUse.tmod` 复制到该文件夹。
3. 返回“管理模组”，启用“持续使用防误触 UI”，重新加载模组。

无需额外前置模组或配置。可以和现有的人物模组一起启用。

## 开关与按键

默认 **F8** 开启/关闭保护，切换时显示中文状态提示。按键可在“设置 → 控制 → 模组快捷键 → 持续使用防误触 UI → 开关持续使用防误触”中修改。

功能默认开启，开关状态随当前角色保存。关闭后，所有输入检查和快捷栏点击使用原版行为；再次开启后，需要松开再按使用键才重新获得保护。鼠标拿着物品或背包打开时也能用开关退出保护。

## 1.0.1 交互修复

1.0.0 会把鼠标抓起的可使用物品误判为持续攻击。1.0.1 排除了鼠标物品和鼠标物品槽（58），不再为这类操作启用攻击保护。鼠标放回物品、拿起物品与丢弃物品保持原版流程；右键和丢弃键也会取消本次按住的保护。

## 使用效果

从游戏区域开始按住“使用物品”键，鼠标滑过增益图标、快捷栏、小地图等 HUD 时，继续按物品原本的规则使用。瞄准仍跟随鼠标所在位置。

- 松开使用键后，停止持续使用，恢复通常的 UI 点击。
- 直接在 UI 上开始按键，不会获得攻击保护；拖出 UI 后仍遵循原版输入规则。
- 持续使用时滑过快捷栏，不会误选另一个槽位。数字键和滚轮仍按原版规则切换物品。
- 鼠标从背包抓起物品时不启用保护；显式右键交互或按丢弃键时，取消本次保护。
- 不改变射速、伤害、资源消耗、自动连用设置或物品的使用条件。
- 不支持自动连用的武器依然需要再次按键；引导类物品仍会在松键时结束引导。
- 打开背包、聊天、设置、全屏地图或 NPC 对话，以及失去游戏焦点、死亡时，取消本次按住的保护。返回游戏后，需要松开再按才能重新获得保护。

本模组只在客户端加载。单人可用；联机中服务器和其他玩家无需安装。联机与其他模组组合的实际游戏表现仍需实测。其他模组如果自行取消攻击，或大幅修改相同输入方法，可能需要单独适配。

## 源代码与构建

`Common/Players/HeldUsePlayer.cs` 跟踪按键是否从游戏区域开始；`Common/Systems/HeldUseInputSystem.cs` 处理 UI 对物品输入的拦截、悬停产生的等待松键状态，以及快捷栏误切换。

程序保留真正的 `mouseInterface` 状态，使提示文字、右键和其他界面逻辑继续工作；只在已保护的按住操作期间绕过两个特定的物品使用检查。`HeldUseKeybindSystem.cs` 注册可修改的 F8 开关。没有改写自动连用、引导或攻击逻辑；仅随角色保存开关状态。

### 在游戏中构建

将整个 `UninterruptedUse` 文件夹放入 tModLoader 的 `ModSources` 文件夹，在“开发模组”中选择“构建并重新加载”。文件夹名应保持为 `UninterruptedUse`。

### 在当前工作目录构建

```powershell
.\tools\build-uninterrupted-use.ps1 -TmlDirectory 'F:\1234\steamapps\common\tModLoader'
```

使用 tModLoader 内置编译器和运行时，无需安装 .NET SDK。产物为 `dist/UninterruptedUse.tmod`，构建时使用 `.validation/UninterruptedUse/build-profile` 隔离目录。
